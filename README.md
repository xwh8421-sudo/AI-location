# AI-location · 分镜连续性检测工具

上传**分镜故事板图片**或粘贴**视频生成 Prompt**，自动检测并给出修改建议：
人物站位、越轴（180° 轴线规则）、视线匹配、动作衔接、服装连续性、道具连续性。

每个问题都附带说明、修改建议和一段**可直接复制使用的修正 Prompt**，并生成每镜的人物站位 / 关系轴线示意图。

---

## ✨ 功能一览

| 检测项 | 判断方式 | 说明 |
| --- | --- | --- |
| 越轴（180° 轴线规则） | 规则引擎 | 多人场景下对**每一对同框角色**分别建立轴线，相邻同框镜头左右位置整体对调即报警 |
| 视线匹配 | 规则引擎 | 对话双方水平朝向相同、无法形成对视时提示 |
| 人物站位 | 规则引擎 | 单人镜头中角色的画面左右方位与已建立的轴线不一致时提示 |
| 道具连续性（持有者突变） | 规则引擎 | 同一道具在相邻出现的镜头中换了手持者且无递接交代 |
| 动作衔接 | 多模态大模型 | 相邻镜头起止动作能否接上、是否缺少过渡镜头 |
| 服装连续性 | 多模态大模型 | 同一角色服装颜色/款式/穿脱状态前后矛盾（描述简略但不冲突不算问题） |
| 道具连续性（消失/位置） | 多模态大模型 | 关键道具无故消失、位置突变 |

其他特性：

- 🎞️ 镜头可**文本 / 图片混用**，支持多选上传、拖拽排序（↑↓）、随时增删
- 🖼️ 站位示意图：人物画面位置、朝向（箭头 / ⊙面向镜头 / ⊗背对镜头）、关系轴线一目了然
- 🔑 API Key 只保存在**浏览器本地**（localStorage），不经任何第三方服务器
- 🎛️ 无需 API Key 也能点「**载入示例**」体验全部检测效果

---

## 🧠 工作原理

1. 每个镜头由多模态大模型解析成结构化 JSON：人物的画面位置、朝向、服装、起止动作、关键道具；
2. **空间规则**（越轴 / 站位 / 视线 / 道具持有者）由本地 Python 规则引擎确定性校验，结果稳定可复现；
3. **语义连续性**（动作衔接 / 服装 / 道具消失）由大模型对整组镜头统一判断；
4. 前端汇总为分级问题清单、站位轴线图和镜头明细。

- Python 3.10+

## ⚙️ 配置

两种方式任选其一：

**方式 A：网页里配置（推荐）**

启动后点击页面右上角「⚙ API 设置」，填入 Base URL、模型名、API Key 即可；弹窗内有 OpenAI / 通义千问的快捷预设。设置仅保存在当前浏览器。

**方式 B：环境变量 / .env 文件**

复制 `.env.example` 为 `.env` 并填写（也可直接设置同名系统环境变量）：

```bash
# OpenAI 官方
OPENAI_API_KEY=sk-xxxx
OPENAI_BASE_URL=https://api.openai.com/v1
MODEL_NAME=gpt-4o

# 通义千问 VL（OpenAI 兼容模式）
# OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

## 🎬 使用流程

1. 点「**载入示例**」先看效果（4 个镜头，内置越轴 + 服装矛盾 + 道具问题 + 动作断裂）；
2. 录入自己的镜头（按顺序排列，可用 ↑↓ 调整）：
   - 底部文本框粘贴视频 Prompt →「＋ 添加为镜头」
   - 「🖼 添加分镜图片」上传故事板（可多选，可补图片说明）
3. 点「**开始检测**」，右侧输出：
   - 问题清单（严重 / 中等 / 轻微分级，附修改建议与修正 Prompt，一键复制）
   - 站位 / 关系轴线示意图（问题镜头红/黄描边）
   - 每个镜头的人物、服装、道具、起止动作明细

## 🛠️ 如何调整检测规则

- **改提示词 / 检查口径**：编辑 `app/prompts.py`
  - ① `SHOT_SYSTEM`：单镜头识别规则（枚举取值、服装/道具怎么记）
  - ② `SHOT_OUTPUT_SPEC`：输出 JSON 格式（字段名被程序依赖，勿随意改）
  - ③ `CONTINUITY_SYSTEM`：跨镜头【检查项】与【定级标准】，直接改中文即可增删/放宽
- **改空间规则**：编辑 `app/rules.py`，文件内按 ①②③ 注释分成越轴、站位、道具持有者三个独立检查块，可单独调整或关闭
- 改完重启服务生效；前端文件刷新页面即生效（已禁用缓存）

## ❓ 常见问题

- **没有 API Key 能用吗？** 可以，点「载入示例」体验完整流程；正式检测自己的镜头才需要配置。
- **接口返回 json_mode 相关报错？** 程序会自动降级为普通调用；若仍失败，请确认所用模型支持视觉输入与 JSON 输出。
- **图片会被保存吗？** 不会。图片以 base64 随请求直接转发给你配置的模型 API，服务端不落盘。
- **端口被占用？** 换一个端口启动：`python -m uvicorn app.main:app --port 8766`
